# PROJECT_CONTEXT.md

## Назначение
Файл для переноса контекста между устройствами/сессиями Codex по проекту `BasepackBot`.

## Как использовать на другом ПК
1. Открыть этот файл.
2. В новом диалоге с Codex отправить:

```text
Обнови память по проекту из файла PROJECT_CONTEXT.md и работай строго по нему.
```

3. После этого давать задачу.

## Текущий стек
- Python bot: `bot.py`
- Google Sheets API: `google_sheets.py`
- Удаление/восстановление записи: `delete_last.py`
- Конфиг ЛРП/весов/принтеров: `devices.py`
- Клавиатуры Telegram: `keyboards.py`
- Весы TCP: `server_scales.py`
- Печать PDF из Google Sheet: `print_google_sheet_pdf.py`

## Ключевая бизнес-логика
- 3 уровня работы: ЛРП -> заказ -> шпуля.
- Бизнес-день со сдвигом на 09:00 (`BUSINESS_DAY_CUTOFF_HOUR = 9`).
- Остаток заказа: `Balance.B - net_today`.
- `net_today` считается по бизнес-дню.
- Нумерация бобин:
  - отдельно для основных и брака;
  - по заказу + ЛРП + бизнес-дню;
  - при сбоях/удалении должна пересинхронизироваться по листу.
- Удаление последней записи:
  - delete: ставится `Eror`, перенос номера из `J` в `K`, `J` очищается;
  - restore: `Eror` снимается, номер из `K` возвращается в `J`, `K` очищается.

## Google Sheets контракт
- Log-листы: `A..K` (заказ, веса, дата, user, Eror, тара, нетто, номенклатура, комментарий, номер, backup номера).
- Лист остатков: `Balance` (`A` заказ, `B` плановый остаток).
- Номенклатура: `Tag` (`A` код, `B` название).
- Имена Log-листов задаются в `devices.py` как `log_sheet_name`.

## Защита и устойчивость
- Таймаут операций с Sheets: `SHEETS_OP_TIMEOUT_SEC = 300`.
- Антидубли/блокировки: `pending_inputs`, `in_flight_requests`.
- Retry на сетевых операциях Telegram/Sheets.
- UTF-8 защита вывода `stdout/stderr`.

## Последние важные решения
- Для команд использовать отдельное сообщение прогресса.
- Для расчета остатка при заказе/шпуле использовать отдельное сообщение прогресса.
- После сообщения остатка отправлять подсказку сканирования шпули.
- В группе не показывать лишние сообщения, только командные сценарии.
